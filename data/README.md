# Data Directory

This directory contains datasets used and generated by the machine learning pipeline.

## Synthetic Data
The `synthetic/` folder contains generated fake datasets that imitate the production backend logs. This is purely synthetic data (not real user data) used to develop and test the ML models without compromising privacy.

### Files
- `login_events.csv`: Records of user login attempts (success, failed, blocked).
- `sessions.csv`: Records of active and ended sessions tied to successful logins.
- `access_events.csv`: Records of resource access requests (allowed, restricted, blocked).
- `ml_training_dataset.csv`: A flattened, combined dataset used directly for training anomaly detection models.
